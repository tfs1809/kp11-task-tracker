# Правила проекта

- Рабочий backend: FastAPI, PostgreSQL и Jinja2.
- Бизнес-правила, права доступа, аудит и московское время обязательны на сервере.
- Не хранить секреты и персональные данные в Git или логах.
- Рабочие данные хранятся только в PostgreSQL.
- Проверки запускаются в контейнерах; непроверенное не отмечается как проверенное.
- UI, маршруты и сценарии задач/событий должны оставаться совместимыми с макетом.
